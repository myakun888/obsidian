# Ecapsulation

adalah konsep oop untuk mengatur cara akses ke properti, dan metod di dalam suatu class

atau bahasa sederhana nya suatu properti itu di bungkus, sepeti capsul

dalam konsep ini ada 3 visiblity modifiers;

**Publick** adalah properti yang dapat di akses dari mana saja
baik dari

- luar, di dalam class, dan di dalam class turunana nya

contoh dari luar

```php

class Rasul {
public $tuhan = "ALLAH SWT";k
public $nama = "Muhammad";
public $agama = 'islam';

public function cek_nama(){

// ini dari dalam class
return $this->nama;
}
}

$nabi = new Rasul ();

// ini dari public
$nabi->nama;
```

```php
class Nabi extend Rasul {


public cek_tuhan() {

// ini turunan yang di akses properti dari class induk
return $this->tuhan;
}
}


$nabi2 = new Nabi();

```
