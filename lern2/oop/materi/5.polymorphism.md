# Polymorphism

berasal dari kata `poly= banyak`, `Morp = bentuk`, artinya satu method yang sama bisa berprilaku berbeda,

**Method overriding**

turunan dapat menimpa method dari parent class

```php


class Hewan {


public function bersuara (){

echo "suara hewan";
}

}


class Kucing extends Hewan (){


public function bersuara (){

echo "meong...";
}

}


class Anjing extends Hewan (){

public function bersuara (){

echo "guukk..guuuk";
}
}
```

### selain override , kita juga bisa menggunkan method barent untuk Polymorphism

caranya kita buat method dengan nama yang berbeda, lalu kita jalan di dalam nya metod parent nya

```php


class Mobil
{

  public function suara_mobil()
  {


    echo "broom...brom";
  }
}


class Sedan extends Mobil
{

  public function suara_sedan()
  {

    $suara_parent = parent::suara_mobil();
    return $suara_parent;
  }
}


$sedan1 = new Sedan();

$sedan1->suara_sedan();

```

dari contoh diatas, ada metohd suara_mobil dari calss Mobil, lal
lalu pada class turunan nya class sedan kita buat metod dengan suara sedan , tapi di dalam nya menjalankan metod parent nya , kita gunakan kataa kunci `parent`
note: parent akan di bahas di materi lain
