# abstract

suatu class yang hanya bisa melakukan extends (turunan) tapi tidak bisa membuat instace object secara langsung

jadi hanya di guanaka sabagai kerangkan untuk class extends

untuk membuat nya selalu di awali dengan kata kunci `abstract`

```php

abstract class Karyawan {

public $nama_perusahaan;
}


class KaryawanTetap extends Karyawan {

}


class KaryawanKontrak extends Karyawan{

}
```

pada contoh di atas , kita tidak bisa membuat object langsung dari abstract class karyawan

```php

$karyawan1 = new Karyawan (); // ini tidak bisa di lakukan

// yang hanya bisa di lakukan class bukan abstarct

// ini semua bisa membuat instace object
$Karyawan2 = new KaryawanTetap();
$Karyawan3 = new KaryawanKontrak();
$Karyawan4 = new KaryawanTetap();
```

## abstract function

selain abstract class ada juga abstract function,
artinya function yang wajib di overide di class turunan nya

abstarct fucntion ini membuat nya menggunakan kata kunci abstarct, dan tidak harus ada isi

unutk isi nya ini nanti saat kita mengoveride di class turunan nya

```php


abstract class Karyawan {

public  $id = 123456789;
pubilc $nama ;


// function biasa, bisa langsung di pakai di class turunan
function ceknama (){
return $this->nama;
}


// abstract function tidak harus ada isi
// dan harus id overide di class turunan nya
abstract function cekid ();
}


class KaryawanTetap extends Karyawan {


public function cekid (){

return $this->id;
}
}

```

pola penting abstract class

- menggunkan kata kunci abstract,
- abstract function wajib di overide atau di buat ulang

## interface

adalah sebuah kontrak yang di dapat di gunakan oleh class
jadi siapa yang melakaukan tanda tangan (implements) maka wajib menggunakan / menjalanakn semua isi nya

- interface hanya berisi function, dan function nya wajib di overide di class yang mengimplementasikan interface tersebut
- satu class dapat melakaukan lebih dari satu interface, berbeda dengan class yang hanya dapat di gunakan / extends 1 kali setiap klass

membuat interface degang kata kunci `interface`

```php


interface support {

public function cekinfo ();

public function cekdata();
}
```

menggunakan interface pada class
menggunkan kata kunci implemnts

```php


class Staff implements support (){

public function $info;

public function cekinfo(){

return $this->info;
}
}
```

jika lebih dari satu interface kita bisa lakukan

```php

interface support {
public function cekinfo ();
public function cekdata();
}

interface helper {

public function cekhelper();
}


class Staff implements support, helper (){

public function $info;

public function cekinfo(){
return $this->info;
}


public function cekhelper (){
echo "ini helper";
}
}




```

jadi kita bisa menambahkan lebih dari satu interface di dalam sebua class

## perbedaan abstract dan interface

- penggunaan
  - interface bisa di pakai bersamaan dengan class lebih dari satu interface
  - abstract class bisa di pakai bersamaan dengan class hanya satu
- properti , construktor
  - abstract boleh punya prpoerti dan function biasa, dan construktor
  - interface tidak boleh punya properti dan construktor, tidak bisa menggunakan function / method biaasa, method nya tidak boleh berisi / harus kosong
