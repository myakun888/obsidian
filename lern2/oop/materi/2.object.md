# Object

object adalah hasil dari cetakan dari classs / instance object

untuk membuat object dari suatu class kita menggunakan kata kunci `new`;

membuat object

```php

class Manusia {


}

$pria = new Manusia();
```

dari contoh di atas kita sudah membuat object dari class Manusia

## construct()

kadang kita ingin membuat object dan mengisi properti sendiri

ini bisa kita gunakan fucntion construct

**fucntion construct**
adalah fucntion yang akan di jalankan pertama kali sebuah object di buat, jadi bisa kita manfaatkan / gunakan untuk mengisi properti atau perameter yang kita perlukan

```php

class Manusia {

public $asal;


public function __construct ($asal){

$this->asal;
}

}

$pria = new Manusia('indonesia');


$pria->asal;
```

## destruct

jika construct adalah function yang pertama kali dijalankan ketika object dibuat,
destruct adalah fucntion yang terakhir kali di jalankan ketika sebuah obejct di buat

ini biasa di gunakna untuk menutup koneksi jika kita membuat object conecksi database

dan juga dapat diguankan tergantung kebutuhan

```php
class Db
{

  public $data = "database";
  public function __construct()
  {

    echo "koneksi berhasil di buat" . PHP_EOL;
  }


  public function __destruct()
  {
    echo "koneksi berhsil di tutup" . PHP_EOL;
  }
}



$con = new Db();

// koneksi berhasil di buat
// koneksi berhasil di tutup
```
