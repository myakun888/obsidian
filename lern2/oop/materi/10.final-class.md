# Final class

saat kita membuat class, kita bisa memngekstend suatu class hingga tak terbatas

untuk menghentikan nya kita bisa menggunakan kata kunci `final`;

sehingga class yang ada kata kunci ini, tidak bisa di extends lagi

```php

class Benua {



}

final class Asia extends Benua {



}


#ini error
class Indonesia extends Asia {

}
```

class Asia tidak bisa lagi di extends karen di class nya sudah kita batasi dengan final class
