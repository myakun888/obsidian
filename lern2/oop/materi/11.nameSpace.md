# NameSpace

saat aplikasi kita besar, biasanya akan ada class dengan nama yang sama, ini akan membuat error / bentrok saat kita menggunakan ny

maka dari itu kita salah satu solusi nya perlu NameSpace untuk mengatasi nya

contoh tanpa namespace

**file.php**

```php

Class Data {

}


```

** info.php**

```php

Class Data {


}
```

**user.php**

```php

require 'file.php';
require 'info.php';



$orang1 = new Data();
$orang2 = new Data();


// ini akan error karena akan bentrok, php tidak tau, class dengan nama Data di miliki oleh 2 file berbeda

```

## Dengan NameSpace

membuat NameSpace cukup dengan kata kunci `NameSpace`

**file.php**

```php


namspace group1;

class Data {

}
```

**info.php**

```php

namespace group2;

class Data{


}
```

menggunakan nya kita menggunakna tand `\` contoh format nya `namaNamespace\namaClassnya`

**user.php**

```php

require 'file.php';
require 'info.php';



$user1 = new group1\Data();
$user1 = new group2\Data();


```

- dalam satu file bisa lebih dari satu namespace

**file1.php**

```php


namespace satu {

class OKe {

}


}

namespace dua {

class siap {

}
}
```

untuk penggunaann dalam satu file yang lebih dari satu namesapce harus di batasi dengan tanda { }

tapi best practice nya satu file itu hanya satu namesapce

## best practice penamaan namespace

dalam penamaan nya namespace itu baiknya megggunakan nama folder / path nya , ini juag berlaku di framework-framework seperti di laravel dan lainya

contoh , pada struktur folder seperti ini

```cmd

informasi/
├── index.php
└── pengguna
    ├── data.php
    └── user.php

```

pada file data.php

```php
namespace informasi\pengguna;

class Data {


}
```

pada file user.php

```php

namespace informasi\pengguna;

class Data {


}

```

> note: untuk bers practice penamaan class itu harus sama dnegan nama file
> pada contoh diaatas hanya contoh agar kita tau beda nya saja

pada file yang inging menggunakan nya contoh `index.php`

**index.php**

```php

require 'pengguna/data.php';
require 'pengguna/user.php';


$pengguna1 = informasi\pengguna\Data();
$pengguna2 = informasi\pengguna\Data();


```

## kata kunci 'use';

saat kita memanggil class yang menggunkan namespace, maka kita harus menulis namespace, jika namespace panjang ya panjang juga, jika di gunkan berkali kali itu juga akan kurang efiesin

untuk mengatasi itu, kita dapat menggunakn kata kunci `use`;

```php

require 'pengguna/data.php';
require 'pengguna/user.php';


// tidak lagi seperti ini
#$pengguna1 = informasi\pengguna\Data();
#$pengguna2 = informasi\pengguna\Data();


#kita cukup menulis


use informasi\pengguna\Data;
use informasi\pengguna\Data as Data2;

$pengguna1 = Data();
$pengguna2 = Data2();
```

kita tidak lagi menggunakan nama namespace yang panjang cukup kita deklarasikan 1 kali dengn use maka kita bisa,

bagaimana jika ada nama yang sama? kita bisa tambahkan kata kunci `as` lalu beri nama baru agar berbeda pada contoh diatas
`use informasi\pengguna\Data as Data2`, selanjut kita gunakan nama `Data2` untuk yang berbeda tadi
