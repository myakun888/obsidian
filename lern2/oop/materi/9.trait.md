# Trait

adalah kumpulan method / function yang dapat di gunakan suatu class , tanpa harus melakukan extends

ini jadi solusi bagi php yang hanya bisa extends 1 class saja

jadi trait bisa di gunakan di semua class tanpa harus extends class / membuat class

contoh

```php

class A {

public function cekdata (){
return 'dataa';
}

}



class b extends A {} // ini bisa paka cek data()


kalau b sudah extends class lain

class b extends informasi {}// class b ini tidak bisa lagi menggunakan atau extends class A, class hanya bisa satu kali enxtends atau hanyna bisa punya satu parents class
```

solusi nya kita bisa gunakan trait

## membuat trait

membuat trait menggunakan kata kunci `use` lalu untuk menggunakan pada class gunakan dengan `implements`

```php
trait salam
{
 public function sapa()
  {
    echo "assalamuaalaikum, dari trait salam" . PHP_EOL;
  }
}


trait panggil {

public function hay (){

echo "hy....";
}
}


class Pria
{
// class pria menggunakan trait salam
  use salam,sapa;
}


$mf = new Pria();
$mf->sapa();
$mf->hay();


```

**keterangan**

- class pria menggunakan trait salam,
  note: jika ingin menggunkan lebih dari satu trait cukup berikah tanda ,

## conflik trait

terkadang kita mengalami confilk trait, yaitu terjadi jika dua trait berbeda memiliki nama function yang sama di dalam nya

```php

trait Salam {

public function sapa (){

echo "assalamuaalaikum ini dari trait sapa";
}
}



trait panggil {

public function sapa (){

echo "assalamuaalaikum ini dari trait panggil"
}
}

class Pria {
use salam,panggil

}



```

dari contoh diatas ini akan error untuk cara mengatasi nya harus secara manual

```php


class Pria {
use salam,panggil{
  salam::sapa insteadOf panggil
  panggil::sapa as sapaBaru
}

}


$man = new Pria ();

$man->sapa() //ini memanggil function sapa dari trait salam
$man->sapaBaru() // ini memanggil function sapa dari trai panggil
```

keterangan

- kita menggunakan kata kunci insteadOf, artinya gunakan trait salam dan function sapa, abaikan dari trait panggil
- untuk traia panggil::sapa ganti dengan nama sapaBaru , jadi kita memnaggil nya dengan nama sapaBaru
