# kata kunci this dan self

## this

adalah kata kunci yang di gunakan untuk mengakses properti dari class saat ini

```php


class Pria {

public  $nama;

public fucntion __construct($namaAnda){


$this->nama;
}
}
```

## static

secara default saat kita membuat properti dan method di suatu class itu akan menempel di isntance objectnya, jadi untuk mengakses nya kita harus membaut object nya terlebih dahulu baru bisa mengakses properti dan method nya

, dengan kata kunci `static`, maka properti tersebut akan menempel di class nya tidak lagi di object nya

```php

class Wni{

public static asal = 'indonesia';
public static function info (){

echo "ini function dari static";
}
}



$warga = new wni ();
$warga->asal // ini akan error



// cara yang benar mengakses nya dengan nama class nya


Wni::asal // indonesia
Wnie::info// ini function dari static
```

## self

digunakan untuk mengakses nama class saat ini , biasa digunakan untuk mengakses properti static di suatu class

untuk mengakses properti static kita bisa mengguanakn nama class nya, tapi jika ingin mengakses dari dalam class best practice, karena juka nama class di ubah maka akan error , untuk best practice jika ingin mengakses dari dalam class nya saat ini mengguankana kata kunci `self`

```php

class Wni{

public static asal = 'indonesia';


public function cekAsal (){
// $this->asal // ini akan error

// Wni::$asal // ini bisa tapi bukan best practice
self::asal;
}
}


$warga = new Wni();


$warga->cekAsal();

```
