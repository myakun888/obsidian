# inheritance (Pewarisan)

adalah perilaku class yang mewarisi properti dan metodh dari class

Class yang mewarisi di sebut `Parent Class / superclass`
Class yang di warisi di sebut child class / subclass

keyword yang di guanakan adalah , extends

## contoh kode

```php

class Hewan
{
  public $nama;

  public $warna = 'hitam';
  public $jenis_kelamin;
  public function __construct($nama, $jenis_kelamin)
  {

    $this->nama = $nama;
    $this->jenis_kelamin = $jenis_kelamin;
  }
}




class Kucing extends Hewan
{

  public function suara_hewan()
  {

    echo "meong...!!";
  }
}

$ketty = new Kucing('ketty', 'perempuan');
$ketty->suara_hewan();

```

_keterangan_
class kucing mewarisi properti, nama, warna, jenis kelamin
lalu menambahkan metod suara hewan

** method overidding**

artinya sebuah child class dapat me overidding metohd dari parent class /super class , dengan implementasi baru

```php


Class Hewan {

public function suara_hewan (){

echo "suara hewan"
}

}


class Kucing extends Hewan {


public function suara_hewan {

echo " meong"
}
}
```

artinya
child class, atau klass dapa melakukan overrid / menimpa suatu metod dengan nama yang sama dan di isi dengan implentasi atau fungsi baru sesaui keperluan
ini juga termasuk `polymophism`
ini akan di bahas di materi lain
