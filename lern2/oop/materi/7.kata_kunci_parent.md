# Parents

kita sudah tau, jika ingin mengakses suatu properti saat ini dari dalam suatu class atau turunan nya kita menggunakan kata kunci `this`, atau kalau properti nya static bisa menggunakan kata kunci `self` yang merujuk pada class saat ini

dan juga kita harus tau perilaku class , jika kita ada nama method yang sama dengan nama method di class induk,
maka class method yang dari class induk akan di timpa / overide

contoh

```php


class Indonesia
{

  public $negara = 'indonesia';

  public function cekNegara()
  {
    echo 'ini class dari super class';
  }
}


class Sumsel extends Indonesia
{

  public function cekNegara()
  {
    echo 'ini dari class sumsel';
  }
}

$kota = new Sumsel ();// ini dari class sumsel
```

pertanyaan nya bagaiaman jika kita nama class nya sama, dan yang ingin di jalankan adalah method cekNegara yang dari class indonesia?
kita tidak bisa menggunakna this,

kata kunci yang di gunakan adalah `parents`

ada 2 solusi

1. jangan buat nama yang sama, jadi kita bisa ambil karena class ny di wariskan
2. jika diharuskan kita membuat / menimpa / memakai nama yang sama untuk keperluan lain, maka kita bisa membuat fucntion dengan nama yang kita ingin kan, dan di dalamnya kita jalankan kata kunci `parant::namametodny`;, karana kata kunci parent akan memangil dari class indux

```php

class Sumsel extends Indonesia
{

  public function cekNegara()
  {
    echo 'ini dari class sumsel';
  }

public function panggil (){

Parent::cekNegara()
}
}

$kota = new Sumsel ();

$kota.cekNegara()// ini dari class sumsel
$kota.panggil()// ini dari super claas


```
